# Lane E requests for the integrator

Changes outside Lane E's files that the mobile app and the download flow need. Lane E stubbed around each of them.

1. **`.gitignore` hides a route (M1 bug).** The pattern `coverage/` also matches `apps/web/src/app/api/v1/bonds/coverage/`, so `bonds/coverage/route.ts` was never committed and `apps/web/src/app/api/v1/routes.test.ts` fails on the M1 baseline ("exists for every contract endpoint"). Anchor the pattern (for example `/coverage/` plus `**/coverage/` only under `packages/*` and `apps/*` roots) or add `!apps/web/src/app/api/v1/bonds/coverage/`, then commit the stub (Lane A owns it).
2. **`routes.test.ts` expects 501 from every route.** Lane E implemented `releases.latest`, `releases.download`, `releases.updater` and `app.latest`; without `GITHUB_RELEASES_TOKEN` they answer 503 `unavailable` (or 404 for an empty asset name) by design. Skip implemented endpoint ids in the "unbuilt endpoints answer 501" case (each lane adds its own ids), and keep the "route file exists" case. Lane E's contract tests are in `apps/web/src/app/api/v1/releases/releases.test.ts` and `apps/web/src/app/api/v1/app/app.test.ts`.
3. **Lockfile.** Lane E added `apps/mobile` with its dependencies (Expo SDK 58, React 19.3 and React Native 0.88 for the app only; the web app keeps React 19.2.4). Regenerate `pnpm-lock.yaml` on merge. No change to `.npmrc` was needed: Expo 58's Metro works with pnpm's isolated `node_modules`.
4. **CI.** Add `node scripts/version.mjs --check` to the `verify` job in `.github/workflows/ci.yml`. PLAN section 12 asks for a mobile job (expo-doctor and a Gradle build when `apps/mobile/**` or `packages/shared/**` change); Lane E covers the Gradle build with the `pull_request` dry run in `mobile-release.yml`, and `pnpm -r test` already runs the app's Jest suite. Optionally add `pnpm --filter mobile doctor` to CI.
5. **Shell (Lane D).** The `[locale]` layout should provide the `<main>` landmark and skip link (the download page renders inside it without its own `<main>`); link `/download` from the footer as well as the nav entry; include `/en/download` and `/ur/download` in `sitemap.ts`.
6. **Shared messages.** The app copies `apps/web/messages/{en,ur}/common.json` into `apps/mobile/src/i18n/web/` (ADR 0005). After Lane D's `common` changes are merged, run `pnpm --filter mobile messages`; the app's test suite fails while the copy is stale.
7. **Firewall rule.** `/api/v1/releases/download/*` spends one GitHub API call per signed URL (reused for a minute per instance). Add a Vercel Firewall rate limit for that path (for example 30 requests per minute per IP) as the outer layer described in PLAN section 11.
8. **Root script (optional).** `"version": "node scripts/version.mjs"` in the root `package.json` so `pnpm run version 1.2.0` works from the root.
