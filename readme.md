# bondcrapo

Monorepo for the **BondCheck** project — a halal financial literacy platform for Pakistan.

## What's here

- [bondcheck-next/](bondcheck-next/) — the Next.js 16 web app (active project)

## Getting started

```bash
cd bondcheck-next
bun install
bun dev
```

Open http://localhost:3000.

See [bondcheck-next/README.md](bondcheck-next/README.md) for the full project README and [bondcheck-next/ROADMAP.md](bondcheck-next/ROADMAP.md) for the product roadmap.
