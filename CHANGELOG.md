# Changelog

All notable changes to BondCheck are documented in this file. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) as generated by git-cliff from conventional commits, and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-06-30

The rebuild: a pnpm monorepo with the website, the Android app and shared packages, replacing the previous single checker app.

### Features

- *(bonds)* Parse official result files and PDFs, official date lists, number search and prizeinfo.net records with recorded fixtures
- *(bonds)* Seed denominations and cited prize structures; split premium 25000 and 40000 draws out of the bearer codes
- *(bonds)* Import the legacy snapshot as a candidate source, validate every draw and reconcile across sources (verified, published, disputed)
- *(bonds)* Idempotent draw commits, a resumable backfill with dry run, and a public coverage report
- *(bonds)* `bonds-sync`, `bonds-verify` and `bonds-schedule` jobs with GitHub Actions schedules and a Vercel Cron safety net
- *(bonds)* `/api/v1/bonds/*` with a rate limited checker for up to 1,000 numbers per request
- *(bonds)* Prize bond hub, denomination, draw, schedule, checker and coverage pages with JSON-LD, in English and Urdu
- *(bonds)* On-device reading of bond numbers from photos and PDFs
- *(markets)* Providers for gold-api.com, MetalpriceAPI, ExchangeRate-API, the CC0 currency API, State Bank rate sheets, Forex.pk and APSGJA rates reported by APP, with fallbacks
- *(markets)* Local gold and silver rates per country derived from spot and FX, with reported values rejected when they stray more than 5% from the estimate
- *(markets)* `metals-spot`, `fx-daily`, `pk-market`, `local-rates-derive` and `housekeeping` jobs, and a resumable history backfill
- *(markets)* `/api/v1/markets/*` with validation, rate limiting and attribution
- *(markets)* Gold, silver, metal and currency pages with an accessible SVG chart, a data table alternative and a converter
- *(wallet)* Anonymous wallet API with cookie and header credentials, hashed tokens and rotating sync codes
- *(wallet)* All-time matching of owned bonds, incremental matching after each new draw and Web Push win alerts
- *(wallet)* My bonds dashboard, bond manager with typed, pasted, range, spreadsheet and scanned input, wins, near misses, settings, export and deletion
- *(wallet)* Local-first cache for offline viewing and a one-time import of the previous app's history
- *(web)* Shell with header, bottom tab bar, footer, language and theme switches, design tokens with light and dark themes and Urdu Nastaliq typography
- *(web)* Landing page with a quick check, live draw and rates board
- *(web)* About, data sources and attribution, Privacy, Terms, offline and not found pages
- *(web)* Installable PWA with a service worker, offline fallback, sitemaps with hreflang alternates, robots.txt and Open Graph images
- *(web)* Locale negotiation in the proxy with `en` and `ur` routes
- *(web)* One validated server environment schema with a single rate limit secret, and `.env.example`
- *(web)* Security headers on every response with a same-origin Content-Security-Policy; the pdf.js and tesseract.js assets are self-hosted
- *(mobile)* Expo Android app: home, checker with camera scanning, results browser, anonymous wallet, gold and currency rates, settings with English and Urdu
- *(mobile)* Draw reminders, win alerts, background result checks and in-app update prompts
- *(download)* Download page with QR code; the private GitHub release is served through the website API
- *(release)* Version script for the workspace and the Expo config, and env based release signing

### Bug Fixes

- *(shared)* Always invoke `fetch` on `globalThis` in `ApiClient` (browsers threw "Illegal invocation")
- *(web)* Send the bond and wallet client islands the messages they use
- *(web)* Use theme tokens in feature pages so dark mode works everywhere; keep QR codes on white
- *(web)* Answer typed errors instead of crashing when a variable is set but empty
- *(wallet)* Allow more wallet creations per shared carrier address

### Performance

- *(web)* Load the wallet API client and contracts after hydration (90 KB gzip less on wallet pages)
- *(web)* Remove the legacy checker and its stylesheet from the bundle
- *(shared)* Mark the package side effect free so unused contracts tree-shake out

### Refactor

- Move the Next.js app to `apps/web` with shared `packages/shared`, `packages/db` and `packages/ingest`
- *(web)* Build the sitemap from the bond and market features' own URL lists

### Testing

- Vitest unit and PGlite integration suites for parsers, validation, jobs, query modules and every API contract
- Playwright suites with axe in both locales and both themes, visual RTL snapshots, PWA, offline and security header checks
- Jest and React Native Testing Library for the Android app

### CI

- Lint, typecheck, unit tests, build, version check and end to end jobs; non-blocking Lighthouse budgets and OpenNext Cloudflare build
- Scheduled ingestion workflows for prize bonds and markets, a backfill workflow and the Android release workflow
- Dependabot for npm packages and GitHub Actions

### Documentation

- README, owner setup guide, contributing guide, security policy, rebuild plan, data audit, architecture decision records, coverage report and mobile release guide

### Removed

- The legacy Python and vanilla JavaScript apps, the unauthenticated admin page and scraper action, device registration and telemetry that stored IP addresses and locations
