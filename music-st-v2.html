LOAD MIDI FILE

Paste a URL to a .mid file. The server must allow CORS. Once loaded, the song appears in your library with the real, accurate transcription.

WHERE TO FIND MIDI FILES

  • BitMidi.com — huge library (most modern hits). Some URLs may need a CORS proxy.
  • Midishrine / FreeMidi / VGMusic — film scores, game music, classical.
  • IMSLP.org — classical sheet music + some MIDI, all public domain.
  • GitHub raw URLs — any public repo with .mid files works (CORS friendly).
